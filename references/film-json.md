# film.json — 全部字段

一部片子 = `meta`（全片设置）+ `geo`（地图，可省）+ `facts`（事实表）+ `frames`（一段段内容）。范例：`examples/zheng-he/film.json`。

## meta

```json
"meta": {
  "slug": "zheng-he",              // 输出文件名
  "title": "郑和下西洋",
  "aspect": "16:9",                // "16:9" 横屏 1920×1080 · "9:16" 竖屏 1080×1920 · "1:1"
  "platform": "x",                 // x | x-premium | douyin | tiktok | shipinhao | youtube — 用来检查时长上限
  "voice": { "provider": "auto",   // 见 audio.md「配音从哪来」
             "speed": 1.0, "tempo": 1.08, "lead": 0.4, "tail": 0.75, "gap": 0.28, "unit": "cue" },
  "progress": { "label": "下西洋", "total": 8 },     // 左下角进度条；不要就省略
  "stationFormat": "第 {n} 站 / 共 {total} 站",      // 标题上方的小字
  "cover": { "title": "郑和下西洋", "sub": "1405 — 1433 · 七下西洋", "note": "8 站 · 全片代码实时渲染",
             "duration": 1.2, "map": { … } },         // 片头封面，见下
  "style": { "route": "#f0b84a", "sea": true, "ramp": "warm" },   // 可选：覆盖叠层和地图的颜色、字体；地图样式见下
  "subtitleMaxChars": 24, "musicLevel": 0.62, "ambienceLevel": 0.30, "musicSeed": 1405
}
```

**地图样式**（写在 `meta.style` 里）：

| 键 | 作用 |
|---|---|
| `route` / `route2` / `dot` / `river` | 主路线、其他路线、地名圆点、河流的颜色 |
| `sea` | 海的画法。不写 = 和底色差不多的暗色（陆上题材，海只在图边）。`true` 或 `"teal"` = 青蓝色的海，沿岸有一圈亮边（航海题材）。也可以写 `{ "shallow": "#…", "deep": "#…", "coast": "#…" }` |
| `ramp` | 陆地按海拔上色。默认 `"ink"`（低地近黑，适合陆上路线）。海多陆少的图用 `"warm"`，陆地整体提亮成暖色，才能和海分开 |
| `edgeFade` | 图的四边往底色里暗下去的宽度（占图宽的比例），默认 0.14。地点靠近图边时调小，或者把 `geo.bbox` 放大 |
| `relief` | 山体阴影的强度，默认 1 |

海岸线是从高程数据里实时切出来的，任何缩放下都是一条清晰的线，不需要另外下载岸线数据。

**封面 cover**：片头第一帧就是封面（平台用第一帧做缩略图，黑场开头会得到一张黑缩略图）。背景二选一：
- 地图：`"map": { 地图镜头配置 }`，通常让整条路线亮着，用 `"draw": { "from": "total", "to": "total", "fadeOut": [0.75, 1.15] }` 让路线随标题淡出。让封面的机位等于第一帧第一个镜头的起始机位，标题淡出后就无缝接上。
- 三维镜头：`"type": "scene", "scene": "<场景文件名>", "shot": "<镜头id>"`（没有地图的片子用这个）。

## geo

有路线、有地名的片子才需要。没有 `geo` 就不能用地图镜头。

```json
"geo": {
  "zoom": 6,                                  // 瓦片层级。6 ≈ 每像素 2 km，够一个大洲；区域片用 7–8
  "bbox": [28, -15, 128, 38],                 // 西、南、东、北（经纬度）
  "places": { "南京": [118.74, 32.07], "古里": [75.78, 11.25], … },    // 地名 → [经度, 纬度]
  "routes": {
    "main": ["南京", [119.6, 32.25], "刘家港", …, "古里"],   // 路线点：地名或 [经度, 纬度]
    "west": ["古里", [74.0, 13.2], …, "忽鲁谟斯"]
  },
  "riverRank": 8                              // 河流细到几级（Natural Earth scalerank），默认 8
}
```

- 路线里**用地名写的点自动成为「节点」**，地图镜头可以按节点名画线（`"from": "满剌加", "to": "锡兰山"`）。
- `main` 是主路线（会发光）；其他名字的路线用地图镜头的 `extra` 画。
- 航线（走海的路线）的中间点要离岸半度到一度，否则平滑后的线会擦着海岸甚至压上陆地。
- 运行 `film.py geo` 先看要下载什么、多大；征得用户同意后 `film.py geo --download`。数据缓存在 `~/.cache/code-doc-film/`，同一地区第二次不用再下。
- **不画任何国界、省界**（原因见 `rules.md`）。

## facts

旁白里出现的每个数字都要在这里有出处。`film.py qa` 会核对：旁白里的阿拉伯数字必须出现在某条 `match` 或 `text` 里，且每条 fact 的 `source` 不能为空。

```json
"facts": [
  { "text": "《明史·郑和传》：将士卒二万七千八百余人，造大舶……者六十二", "match": ["62", "27,800"], "source": "https://zh.wikisource.org/zh-hans/明史/卷304" },
  { "text": "满剌加：宝船到彼，立排栅、盖造库藏仓廒（《瀛涯胜览》）", "match": [], "source": "https://zh.wikisource.org/zh-hans/瀛涯勝覽 （原文未逐字核对）" }
]
```

没核到链接、没逐字核对原文的要如实写出来，交付时告诉用户——不要编一个链接。

## frames

```json
{ "id": "ceylon",                  // 唯一 id（也是配音文件名 audio/<id>.wav）
  "scene": "f06_ceylon",           // scenes/f06_ceylon.js；只有地图镜头的帧不写
  "station": 4,                    // 第几站 → 进度条和「第 4 站 / 共 8 站」；不是站点的帧不写
  "stamp": { "title": "锡兰山", "date": "1409 · 2 · 15", "place": "今斯里兰卡" },   // 左上角；false = 不显示
  "narration": ["1409年，锡兰山，今天的斯里兰卡。", "郑和在这里立下一块石碑，", "…"],
  "shots": [ … ],
  "callouts": [ … ],
  "music": "tension",              // 可选：整帧默认情绪，或一组按句切的段落（见下）
  "lead": 0.4, "tail": 0.75,       // 可选：这一帧配音前后的留白（秒）
  "duration": 3.0 }                // 只有不带旁白的帧才写
```

**narration 写成数组，一个元素一句（cue）。** 下标就是 `cue:0`、`cue:1`…… 一句里有两个画面节拍时，在逗号、冒号处拆成两句（`"《明史》记载：大船62艘，"`, `"将士27,800余人。"`），这样镜头才有地方切。每句 6–22 个字读起来最舒服；字幕超过 24 字会自动在标点处折成两条。

运行 `film.py cues` 可以随时列出每帧的句子下标和估算时长。

## 时间表达式

凡是写时间的地方都可以用：

| 写法 | 含义 |
|---|---|
| `3.2` | 秒 |
| `"cue:2"` | 第 2 句开始的时刻 |
| `"cue:2+0.5"` / `"cue:2-0.3"` | 第 2 句开始前后偏移 |
| `"cueEnd:2"` | 第 2 句结束的时刻 |
| `"end"` / `"end-0.4"` | 这一帧结束（前 0.4 秒） |

`shots[].until`、`callouts[].at/until` 里的时间是**帧内时间**；`map`、`card` 里的时间（`t`、`a`、`b`、`draw`、`fadeOut`、`flashAt`）是**镜头内时间**，同样可以写 `"cue:N"`，会自动换算。

## shots

一帧按顺序分成几个镜头。每个镜头从上一个结束处开始，到 `until` 结束；最后一个镜头到帧尾。

```json
{ "id": "anchor",                          // 三维镜头：scenes 文件里 shots.anchor(…)
  "until": "cue:2+0.5",
  "in": { "color": "mist", "dur": 0.5 },   // 入场：默认从黑淡入 0.3–0.4 秒；"cut" = 硬切；颜色 black | mist | dark | white | "#rrggbb"
  "out": { "color": "black", "dur": 1.1 }, // 出场：默认硬切
  "stamp": { "place": "福建 · 长乐" },      // 覆盖帧的 stamp（可只改某几项）
  "music": { "mood": "calm", "chord": "Bb", "level": 0.8 },
  "ambience": ["lake", "night"],
  "card": { "title": "郑和下西洋", "sub": "1405 — 1433", "a": "cue:2+0.2", "b": "end" } }   // 居中大标题卡（片尾用）
```

带 `"map": {…}` 的就是地图镜头，不需要场景代码。镜头不足 1 秒会被检查脚本警告（看不清）。

## 地图镜头 map

```json
"map": {
  "from": "锡兰山",                    // 机位对准的点：地名 | [经度, 纬度] | { "place": "古里", "dx": 30, "dz": 0 }（dx/dz 为地图像素）
  "to": { "place": "古里", "dx": 30 }, // 省略则不移动
  "fit": ["南京", "麻林", "忽鲁谟斯"],   // 或者：自动取景，把这些点都框进画面（代替 from/to/dist）
                                       // 要移动就写 { "from": [点…], "to": [点…] }：从一个取景滑到另一个。新地区不知道像素距离时用它最省事
  "dist": [460, 330],                  // 机位距离（地图像素）：数字或 [起, 止]；越小越近
  "pitch": [60, 62], "yaw": [-4, 5],   // 俯角、水平转角（度）
  "draw": { "from": "锡兰山", "to": "古里", "t": [0.1, 2.6] },      // 把主路线从哪画到哪、用多久
  "extra": [{ "route": "west", "t": [0.2, 3.0] }],                 // 其他路线
  "dots": ["锡兰山", "古里"],                                       // 亮起的地名圆点
  "pins": [ { "place": "古里", "a": 1.8 },                          // 地名标签；a/b = 出现/消失时间
            { "ll": [65.5, 16.5], "text": "阿拉伯海", "kind": "river" },
            { "place": "满剌加", "dx": -40, "dz": -30, "text": "马六甲海峡", "kind": "river" } ],
  "decor": [ … ],
  "post": { "bloom": 0.9 }
}
```

`fit` 会把列出的点放进画面里**没有标题和字幕的那块区域**（按真实的机位投影算，俯角、转角都算进去）。想让主体偏向一边（给右侧的大数字让位），就在 `fit` 里加一个空的经纬度点把画面「撑」过去，比如 `[137, 12]`。

`draw.from` / `draw.to` 可以是：节点名（`"古里"`）、节点名加偏移（`"刘家港+60"`，地图像素）、`"start"`、`"total"`、两节点之间（`{ "between": ["占城", "爪哇"], "k": 0.45 }`）。整条线保持不动写 `{ "from": "total", "to": "total" }`。`"fadeOut": [t0, t1]` 让线淡出。

标签 `kind`：`"gold"`（默认，地名）、`"river"`（斜体水蓝）、`""`（白字）。标签会自动避让；地点不在画面里时标签不显示。

**装饰 decor**（示意线、箭头、圈——比如风向、洋流、一片海域、对峙的两方）：

```json
{ "id": "l1", "type": "line",  "pts": [[105.0, 6.0], [108.0, 3.0]], "width": 2.2, "color": "#8d959b",
  "draw": [0.1, 0.7], "alpha": 0.9, "flashAt": 1.0, "flashColor": "#b8403a" }      // 到时刻变色
{ "id": "wind", "type": "arrow", "pts": [[122, 28], [117, 22], [112, 17]], "dash": 6, "fadeOut": [2.9, 3.7] }
{ "id": "ring", "type": "ring", "center": [80.2, 6.0], "r": 62, "dash": 7, "pulse": 0.64 }  // r 为地图像素；pulse 为闪动频率 Hz
```

同一个 `id` 在相邻镜头里重复出现时沿用同一个物体，所以「下一个镜头里让它淡出」只要再写一遍并加 `fadeOut`。

## callouts

右侧的大数字。一个数字只讲一件事，和旁白说到它的那一句同时出现。

```json
{ "cue": 1, "num": "62", "unit": "艘大船 ·《明史》" }                       // 第 1 句开始后 0.2 秒出现，到这句结束
{ "cue": 1, "delay": 0.4, "until": "end-0.3", "num": "87", "unit": "年前 · 1405 年", "red": true }
{ "at": 1.6, "until": 3.2, "num": "3", "unit": "种文字" }                    // 直接给时间
{ "cue": 2, "count": [0, 27800], "countDur": 1.8, "num": "27,800", "unit": "人", "unitAfter": "余人" }   // 数字滚动
{ "cue": 3, "num": "麒麟", "unit": "= 长颈鹿", "small": true }               // 文字型标注用 small
```

不要让标注和字幕说同一句话；标注是「把那个数字放大」，字幕是整句。

## 配乐与环境声

每个镜头写 `music`（情绪名，或 `{ mood, chord, level, bright, drums, horn }`）和 `ambience`（标签数组）。也可以在帧上写一组独立于镜头的段落：

```json
"music": [{ "until": "cue:2", "mood": "hope", "chord": "F" }, { "until": "end", "mood": "resolve", "chord": "D" }]
```

情绪和环境声标签的清单见 `audio.md`。
